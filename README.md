# H3art 作品发布合集

以下版本在本机打开或安装。安装包、视频和校验值见仓库的 **Releases** 页。

| 作品 | 版本 | 打开方式 |
| --- | --- | --- |
| [豆屿拼豆工作室](products/douyu) | 安卓离线 App、Windows 单文件工具 | 安卓安装 `douyu-android.apk`。电脑解压 `douyu-windows-offline.zip` 后打开 HTML。图纸和项目在设备上处理。 |
| [抖音混音台](products/audio-mixer) | Windows 本地工具 | 解压 `audio-mixer-windows.zip`，准备 Python 和 FFmpeg 后双击 `start.bat`。 |
| [摇滚人格测试](products/rock-personality) | HTML 体验版 | 下载 `rock-personality.html` 后用浏览器打开，结果以娱乐为用途。 |
| [烛之影](products/candle-shadow) | Windows 试玩版 | 解压 `candle-shadow-windows-demo.zip` 并运行 `CandleShadow.exe`。包含一个可结案的蜡烛投影谜题。 |
| [宝石工坊](products/gemcraft) | Windows PC 0.8 试玩 | 解压 `gemcraft-pc-0.8.zip`，保留 Windows 文件夹完整后运行 `Gemcraft.exe`。 |
| [汉字树 EP01《青》](products/hanzi-tree-ep01) | 5 分 31 秒视频 | 播放 `hanzi-tree-ep01-qing.mp4`。有音乐、音效和画面内双语字幕。 |

从 Releases 下载的文件可用同页 `SHA256SUMS.txt` 检验。各工具使用说明及第三方许可随对应作品。
