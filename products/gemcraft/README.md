# 宝石工坊 PC 原型 0.8

Unity 2022.1.24f1 / Windows x64。运行 Start-Gemcraft.cmd，或解压试玩包后运行 Windows/Gemcraft.exe，保留同目录全部内容。

## 操作

- WASD 行走，鼠标环顾，Shift 快走，Esc 菜单，H 操作说明。
- 靠近工作台按 E 进入修整，E 返回行走。中键拖动调整工作视角，Alt + 滚轮推拉镜头，Home 回正。
- F 拿起瞄准的工具或矿物，再按 F 松手。修整台拾取矿物后自动回到自由行走。
- 持物时鼠标正常转向、滚轮调节距离；Alt + 右键单独转动物品。物品保留拾取时朝向，随人移动，碰到障碍会缩近，放手后受重力掉落。
- B 将手持矿物放上空修整座。修整时右键只转动座上矿石，独立宝石保留自己的位置。
- 1 拿锤子、2 拿刻刀，需要工具在附近。左键选点长按，松开加工；空手或拿着矿物时不能加工。
- G 放大眼镜，戴镜后滚轮调倍率；Q 弱点辅助；R 重置；N 随机矿石。
- 对准已完全剥离的宝石，查看价格，按 V 立即出售这一颗。拿在手里的宝石也可按 V 出售。没有验收单；其他矿物继续留在原地。

## 本版变化

矿石外壳改用随机岩面和宽大断面，加入矿脉、杂质和较干燥的岩质明暗。随机尺寸、晶种、位置、硬度、脆度及累积受力保留。固定种子可以重现；敲击不会临时抽奖。

独立完整晶体增加窄棱面，区分平截端与尖端。着色采用较实的有色晶芯、环境反射与风格化高光；损伤后恢复不规则可破坏表面。仍是程序美术，没有真实体积折射。

敲击、刮削、矿物落地和售出使用分层合成音效。敲击及落地加入多版本与音高变化，落地音量跟碰撞速度变化，软垫接触减弱声音。没有使用第三方音频素材。

## 经济与存档

单颗售价由实际剩余材料、晶种基价及损伤计算。含岩壳的混合矿块不能作为完全剥离宝石直接出售。成交只扣除选中的那颗材料，保留其他矿物的位置和速度，不能重复结算同一颗。钱包余额与成交笔数保存到 PlayerPrefs；未完成矿石、房间摆放和工具位置暂不保存。价格是游戏数值。

## 当前边界与验证

这是粗模原型。破坏精度为 0.025 米材料格，自由物件使用刚体和凸碰撞近似。R/N 会清除当前未售矿石及分离晶体；它们仍是原型测试快捷键。

Build-PC.ps1 编译并执行材料规则检查。Gemcraft.exe --gemcraft-smoke -logFile 完整路径 执行原生自动验证，覆盖材料、拾取、转向、掉落、碰撞、网格重建及单颗出售。全露晶和落物截图使用测试样本，不等同完整玩家提取流程。尚需长期游玩、真实键鼠路径和不同硬件验证。

保留禁用 Graphics Jobs 与单线程渲染，避开本机 Unity 2022.1 退出时的原生问题。研究参考见 docs/visual-references-0.7.md，不分发其他游戏素材。
