# 抖音混音台

本地运行的音频处理工具。拖音频或视频进去，出来一个可以直接发抖音的版本。

**不上传媒体。Windows 需要 Python 和 FFmpeg** —— 文件始终在你自己电脑上。

---

## 怎么用

**双击 `start.bat`**。

会弹出一个黑色窗口，然后自动打开浏览器。窗口别关，关了服务就停了。

如果浏览器没自动打开，手动访问：`http://127.0.0.1:8787`

### 操作流程

1. 把音频或视频拖进虚线框（或点击选择）
2. 调参数 —— 默认值已经适合大多数情况，可以先不调
3. 点「开始处理」
4. A/B 对比试听，满意了点「下载成品」

---

## 参数怎么选

| 参数 | 建议 |
|---|---|
| **降噪强度** | **弹唱素材建议用「轻」**（原因见下节）。纯口播人声可以用「中」 |
| **去低频隆隆声** | 默认开。压掉 75Hz 以下的空调声、桌面震动、手持噪声 |
| **齿音柔化** | 只在「嘶」「呲」音刺耳时开。正常情况别开，会损失清晰度 |
| **动态压缩** | 想要"贴耳"的短视频感可以开。唱歌素材慎开，会压掉感情 |
| **目标响度** | 保持 **-14 LUFS**。这是抖音等平台的通用标准，调高了平台会给你压回来 |
| **输出格式** | 音频投 M4A 最稳，MP3 最通用；视频默认直接出视频 |

## 户外弹唱的实际情况（实测结论）

拿模拟的「吉他 + 人声 + 户外噪音」实测过，几个结论反直觉但重要：

- **降噪在这类素材上是零和的**：压掉多少噪音，就削掉多少吉他高频。
  实测「强」档压了 2.3 dB 噪音、同时削掉 **2.6 dB** 的琴声泛音 —— **不划算**。
  根源是谱减法分不清「宽带噪音」和「乐器泛音」，而吉他是全频段乐器，永远第一个挨刀。
- **「轻」档是更合理的选择**，宁可有残留噪音，也别把琴声弄闷。
- **唯一确定划算的是低频处理**：两级高通（110Hz）单独就压掉 1.0 dB 噪音，
  而信号只损失 0.3 dB。因为风噪集中在低频，跟吉他的高频泛音不打架。
- **车声、人声、鸟叫这类非稳态噪音，后期基本无解** —— 需要 AI 降噪模型，
  但那种模型是为语音优化的，会把你的吉他当噪音一起干掉。
- **录音端比后期重要得多**：防风毛套、麦克风靠近嘴、背风站位 ——
  这三件事的效果远超任何后期处理。

一句话：**后期只能修饰，救不了糟糕的录音。**

---

## 它到底做了什么

处理链（顺序执行）：

```
高通滤波 → FFT 降噪 → 齿音柔化 → 动态压缩 → 两遍响度归一化
```

关键在**两遍响度归一化**：

1. 第一遍：完整跑一遍滤镜链，用 EBU R128 标准**测量**实际响度
2. 第二遍：带着测量结果做**线性**归一化

比常见的单遍动态归一化质量高得多 —— 单遍会实时压动态、听感发闷，线性归一化只做整体增益，不改变动态。

导出统一为：**44100 Hz / 立体声 / 真峰值 -1.5 dBTP**。

## 支持的文件

- **音频**：wav / mp3 / m4a / aac / flac / ogg / opus / wma / aiff / amr
- **视频**：mp4 / mov / mkv / avi / m4v / webm

单个文件上限 400MB。

### 视频进出

拖视频进去，**出来还是视频** —— 画面原样复制、一帧都不重编码，只把音轨换成修好的。

因为视频流是直接复制而不是重新编码，所以：

- **快**：6 秒视频约 1.5 秒处理完
- **画面零损失**：不会有二次压缩的糊
- **音画不会漂**：时长与原始一致

只想要音频的话，在「输出格式」里切成 M4A / MP3 就行。

## 常见问题

**黑窗口一闪就没了 / 提示找不到 Python**
说明这台机器上没装 Python。装一个 Python 3.9 以上版本，或者打开 `start.bat`，把 `PY` 那几行的路径改成你自己的 Python 路径。

**提示端口 8787 被占用**
说明已经开着一个了。直接打开浏览器访问 `http://127.0.0.1:8787` 就行，不用再启动。

**提示找不到 ffmpeg**
把 `ffmpeg.exe` 放到 `C:\ffmpeg\bin\` 下，或者把 ffmpeg 目录加进系统 PATH。

**提示「这个视频没有音轨」**
那个视频是无声的，没东西可处理。

**处理完声音变怪了**
降噪开太强。退回「轻」档，或者直接关掉降噪只做响度标准化。

**处理很慢**
正常。两遍处理意味着要完整跑两遍音频。10 分钟的口播大约 20-40 秒。

## 文件结构

```
audio-mixer/
├── start.bat          双击这个
├── server.py          后端（纯标准库 + ffmpeg，无第三方依赖）
├── web/
│   └── index.html     前端界面
├── workspace/         运行时产物，超过 7 天自动清理
│   ├── uploads/
│   └── outputs/
└── _test/             回归测试（改完代码可以重跑）
    ├── test.sh            音频接口层（11 项）
    ├── test_video.sh      视频进出（含画面零重编码校验）
    ├── run_e2e.sh         浏览器 E2E 启动器，可传脚本名
    ├── e2e.js             音频路径前端（26 项）
    ├── e2e_video.js       视频路径前端（16 项）
    └── outdoor_probe*.py  户外场景降噪实测脚本
```

## 改完代码怎么验证

```bash
# 音频接口层：11 项
bash _test/test.sh

# 视频进出：含「画面是否被重编码」的指纹校验
bash _test/test_video.sh

# 浏览器端（需要 Chrome）
bash _test/run_e2e.sh                      # 音频路径 26 项
bash _test/run_e2e.sh _test/e2e_video.js   # 视频路径 16 项
```
